GQ Store

Un catalogue informatique en ligne premium pour GQ Store : le visiteur découvre les PC, accessoires et consommables disponibles, recherche et filtre le catalogue, ajoute des articles à un panier, puis envoie sa demande de commande à GQ Store via WhatsApp. Aucun paiement en ligne — WhatsApp est le canal de conversion. Un back-office protégé permet à GQ Store de gérer produits, catégories, stock, images et SEO sans développeur.

Node.js Express HTML / CSS / JS vanilla Rendu HTML côté serveur PostgreSQL Prisma Cloudinary Render Mobile First

Ce que fait le site

  • Parcourir le catalogue

    Une grille de produits aérée, organisée par catégories, avec grandes photos et prix en FCFA.

  • Rechercher un produit

    Recherche globale par nom, marque, référence, catégorie et caractéristiques. « ThinkPad » ramène tous les ThinkPad.

  • Filtrer et trier

    Filtres construits dynamiquement à partir des produits réellement en catalogue : marque, prix, processeur, RAM, stockage, écran, état, disponibilité.

  • Consulter une fiche produit

    Galerie photos, prix, disponibilité, référence, tableau de caractéristiques, description et produits similaires.

  • Constituer un panier

    Ajout, quantités, suppression et total indicatif. Le panier reste dans le navigateur et survit au rechargement, sans aucun compte.

  • Commander sur WhatsApp

    Un clic ouvre WhatsApp avec un message pré-rempli listant les produits, les quantités et le total indicatif.

  • Gérer le catalogue

    Back-office protégé : produits, catégories, marques, caractéristiques, photos et stock, sans développeur.

  • Être trouvé sur Google

    Chaque produit publié génère automatiquement son URL propre, ses metadata, ses données structurées et son entrée au sitemap.

Identité visuelle

Le logo GQ·STORE pose la règle : violet profond en signature, argenté en détail, blanc en base. Le site vise 80–90 % de blanc et de neutres pour 10–20 % de violet. Le violet est réservé aux boutons principaux, liens importants, badges, icônes actives et CTA. Le fond général reste blanc. Style : premium, minimaliste, technologique — beaucoup d'espace, grandes photos, bordures très légères, ombres presque imperceptibles, micro-interactions discrètes. À proscrire : gradients marqués, ombres fortes, glassmorphism, animations partout, multiplication des couleurs, rendu « template e-commerce ».

Point de départ

Le dépôt est vide : aucun starter, aucun code existant. Rien n'est fourni d'avance — tout est construit au jalon 1. Ce qui est déjà décidé et n'a plus à être rediscuté :

  • Serveur Node.js + Express
  • Pages HTML rendues côté serveur
  • CSS et JavaScript vanilla, sans framework front
  • PostgreSQL via Prisma
  • Photos hébergées chez Cloudinary
  • Hébergement Render (web + base de données)
  • Conception Mobile First
  • Prix en FCFA, site en français
  • Un seul compte administrateur en v1

Hors périmètre (v1)

  • Paiement en ligne — ni Stripe, ni carte bancaire, ni portefeuille électronique. La transaction se conclut avec GQ Store sur WhatsApp.
  • Tunnel de commande classique — pas d'étapes de checkout, pas de statuts de commande, pas de facturation automatique.
  • Compte client — aucune inscription pour commander. Le panier vit dans le navigateur du visiteur.
  • Gestion de livraison — frais, zones et suivi se négocient dans la conversation WhatsApp.
  • Marketplace multi-vendeurs — un seul vendeur : GQ Store.
  • Avis et notes clients — demande de la modération et du volume ; sans intérêt au lancement.
  • Comparateur de produits — la fiche produit et les filtres suffisent pour choisir en v1.
  • Liste de souhaits / favoris — le panier joue déjà ce rôle sans compte.
  • Alerte retour en stock — le visiteur peut déjà écrire sur WhatsApp depuis la fiche produit.
  • Blog et contenu éditorial — le SEO de la v1 repose sur les pages produits et catégories.
  • Site multilingue — français uniquement.
  • Statistiques de visite avancées — le tableau de bord se limite aux compteurs du catalogue.
  • Plusieurs administrateurs et rôles — un seul compte admin en v1 ; le modèle pourra évoluer ensuite.
  • Application mobile — le site responsive Mobile First couvre l'usage téléphone.

Services externes

Cloudinary

Photos produits

Range les photos ailleurs que sur le serveur — Render efface les fichiers écrits sur disque à chaque redéploiement. Cloudinary redimensionne et convertit aussi les images en WebP/AVIF automatiquement, ce qui règle une bonne partie de l'objectif de performance.

À obtenir

  • Compte Cloudinary (offre gratuite)
  • Nom du cloud, clé API et secret API

WhatsApp

Canal de commande

Le site ouvre simplement une conversation WhatsApp avec un message pré-rempli. Ce n'est pas l'API WhatsApp Business : aucun compte développeur, aucune validation Meta, aucun coût. Un numéro qui reçoit WhatsApp suffit.

À obtenir

  • Le numéro WhatsApp de GQ Store, au format international

Render

Hébergement

Fait tourner le site en ligne et héberge la base de données PostgreSQL. Le nom de domaine se branche dessus, avec le certificat HTTPS fourni.

À obtenir

  • Compte Render (web service + PostgreSQL)
  • Nom de domaine acheté (ex. gqstore.com)

Google Search Console

Référencement

Outil gratuit de Google pour déclarer le sitemap et suivre l'indexation des pages produits. Rien à coder : une vérification de propriété du domaine au déploiement.

À obtenir

  • Compte Google + accès au domaine pour la vérification

Le SEO automatique n'est pas un classement automatique. Le système génère la partie technique — URLs, metadata, données structurées, sitemap. Le positionnement réel dépend de la qualité des fiches, de la concurrence, des recherches réelles et de l'autorité du domaine.

Jalons

1

Fondations & back-office

GQ Store peut se connecter à son back-office et remplir son catalogue de bout en bout : catégories, marques, produits, caractéristiques, photos, stock. Rien n'est encore visible côté public — mais toute la matière du site existe.

Ce qui est construit

  • Écran de connexion et déconnexion sur /admin, inaccessible sans identifiants
  • Tableau de bord : « Bonjour GQ Store », compteurs produits / catégories / disponibles / ruptures
  • Listes de raccourcis : produits récemment ajoutés, produits en rupture, produits mis en avant, bouton « Ajouter un produit »
  • Liste de produits avec recherche, et actions modifier / supprimer / dupliquer / masquer / mettre en avant
  • Formulaire produit : nom, marque, catégorie, description, prix, prix promo, référence, état saisi librement, stock
  • Caractéristiques libres, ajoutées ligne par ligne, avec suggestion des libellés déjà utilisés
  • Photos multiples envoyées vers Cloudinary : choix de l'image principale, réorganisation, suppression, texte alternatif
  • Gestion des catégories et des marques : créer, modifier, supprimer, réorganiser, masquer

Pas dans ce jalon

  • Aucune page publique — ni accueil, ni catalogue, ni fiche produit
  • Panier et WhatsApp
  • Génération SEO automatique, sitemap, robots
  • Habillage graphique poussé du back-office : lisible et sobre suffit
  • Plusieurs comptes admin, rôles, réinitialisation de mot de passe par email
  • Import en masse de produits (CSV, Excel)

Terminé quand : vous vous connectez à /admin, créez une catégorie et une marque, publiez un produit avec trois photos et cinq caractéristiques, modifiez son stock, le masquez puis le réaffichez — et qu'en navigation privée /admin renvoie vers la page de connexion.

2

Site public

Le catalogue devient visible et navigable, à l'identité GQ Store. Un visiteur sur téléphone trouve un produit, le filtre, le compare et consulte sa fiche complète. Il ne peut pas encore commander.

Ce qui est construit

  • Charte GQ appliquée : palette violet/blanc/argenté, typographie, espacements, bordures légères, composants de base réutilisables
  • En-tête avec logo, navigation, recherche ; pied de page avec navigation, contact, horaires
  • Accueil : hero sobre, deux appels à l'action, sélection de produits mis en avant
  • /catalogue en grille aérée, avec tri et chargement progressif ou pagination
  • Pages catégorie /catalogue/{slug} avec leur texte de présentation
  • Recherche globale sur nom, marque, référence, catégorie et caractéristiques
  • Filtres construits à partir des produits existants — panneau glissant sur mobile, colonne latérale sur desktop
  • Fiche produit /produits/{slug} : galerie, prix (et prix barré si promo), disponibilité, référence, tableau de caractéristiques, description, produits similaires
  • Badge « Disponible » ou « Rupture de stock » sur les cartes et les fiches

Pas dans ce jalon

  • Panier, bouton flottant, message WhatsApp
  • Metadata SEO automatiques, données structurées, sitemap
  • Optimisation fine des images et des performances (jalon 5)
  • Zoom sur les photos, vidéos produit, visite 360°
  • Formulaire de contact — le contact passe par WhatsApp et le téléphone

Terminé quand : depuis un téléphone, vous parcourez le catalogue, filtrez par marque et par prix, cherchez « ThinkPad » et obtenez les bons résultats, ouvrez une fiche produit avec galerie et caractéristiques — et qu'un produit à stock zéro affiche « Rupture de stock ».

3

Panier & commande WhatsApp

Le catalogue devient commercial : le visiteur constitue sa sélection et l'envoie à GQ Store sur WhatsApp en un clic. C'est le jalon qui transforme la consultation en demande de commande.

Ce qui est construit

  • Bouton « Ajouter au panier » sur la fiche produit et sur les cartes du catalogue
  • Compteur d'articles dans l'en-tête, visible sur mobile
  • Page panier : lignes produit avec photo, prix, quantité modifiable, suppression, et « Total indicatif » en FCFA
  • Panier conservé dans le navigateur : il survit au rechargement et à la fermeture de l'onglet
  • Panier vide illustré, avec un lien de retour au catalogue
  • « Commander sur WhatsApp » : ouvre WhatsApp avec le message pré-rempli listant produits, quantités et total indicatif
  • « Commander sur WhatsApp » également disponible directement depuis une fiche produit, pour un seul article
  • Bouton WhatsApp flottant en bas à droite, discret, ne masquant aucun élément important
  • « Ajouter au panier » désactivé sur un produit en rupture

Pas dans ce jalon

  • Tout paiement, toute saisie de carte bancaire
  • Enregistrement du panier côté serveur, historique de commandes, relance de panier abandonné
  • Codes promo, frais de livraison, calcul de taxes
  • Vérification en direct du stock au moment de l'envoi WhatsApp
  • Notification email ou tableau des demandes côté admin

Terminé quand : vous ajoutez deux produits au panier, modifiez une quantité, rechargez la page sans rien perdre, puis cliquez « Commander sur WhatsApp » et voyez WhatsApp s'ouvrir avec un message contenant les deux produits, leurs quantités et le total indicatif.

4

SEO automatique

Publier un produit suffit à le rendre trouvable : le site fabrique seul son adresse, ses metadata, ses données structurées et son entrée au sitemap. C'est ce qui alimente le parcours « arrivée depuis Google ».

Ce qui est construit

  • Adresse lisible générée à la création : /produits/lenovo-thinkpad-t14-gen-2
  • Titre de page, description, H1 et textes alternatifs générés à partir de la fiche
  • Champs SEO modifiables par l'admin, qui prennent le pas sur le texte généré
  • Données structurées Product : nom, image, description, marque, prix, devise, disponibilité
  • Fil d'Ariane affiché et déclaré en données structurées
  • Aperçus de partage (Open Graph) avec la photo principale du produit
  • Adresse canonique sur chaque page, y compris sous filtres et pagination
  • Pages catégorie indexables avec leur propre titre, description et contenu
  • /sitemap.xml à jour automatiquement, ne listant que les pages, catégories et produits visibles
  • /robots.txt excluant /admin de l'indexation

Pas dans ce jalon

  • Rédaction de contenu marketing ou de fiches produits par le système
  • Blog, pages d'atterrissage thématiques, netlinking
  • Google Analytics, Tag Manager, pixels publicitaires
  • Flux produits Google Merchant Center ou Facebook
  • Traductions et balises de langue alternatives

Terminé quand : un produit créé dans le back-office apparaît dans /sitemap.xml avec une adresse propre, que sa page contient titre, description, canonique, aperçu de partage et données structurées Product valides, que /robots.txt exclut /admin — et que masquer le produit le retire du sitemap.

5

Finition, sécurité & mise en ligne

Le site passe de « ça marche » à « c'est en ligne, c'est rapide et c'est sûr ». Aucune fonctionnalité nouvelle : on serre les boulons et on livre.

Ce qui est construit

  • Images servies au bon format et à la bonne taille, chargement différé hors écran
  • Allègement du CSS et du JavaScript, mise en cache des pages et des ressources
  • Passe complète sur mobile : cibles tactiles, panneaux de filtres, lisibilité, panier, bouton WhatsApp
  • Durcissement de la sécurité : mot de passe chiffré, session robuste, protection des routes et des API d'administration, limitation des tentatives de connexion
  • Page 404 aux couleurs GQ Store, avec retour au catalogue
  • Tests des parcours critiques : publication d'un produit, recherche, filtre, panier, message WhatsApp
  • Mise en ligne sur Render (service web + PostgreSQL), variables d'environnement, domaine personnalisé en HTTPS
  • Sitemap déclaré dans Google Search Console
  • Relecture des critères d'acceptation, un par un

Pas dans ce jalon

  • Toute fonctionnalité nouvelle
  • Supervision avancée, alertes, suivi d'erreurs tiers
  • Chaîne d'intégration continue élaborée
  • CDN tiers supplémentaire devant Render
  • Stratégie de sauvegarde et de restauration de base de données au-delà de ce que Render fournit

Terminé quand : le site est accessible en ligne sur le domaine de GQ Store en HTTPS, qu'un audit Lighthouse mobile donne au moins 90 en performance et en SEO, et que les 23 critères d'acceptation ci-dessous sont tous cochés.

Critères d'acceptation

Le projet est considéré comme livré lorsque les 23 points suivants sont vrais.

  • L'admin peut créer un produit.
  • L'admin peut modifier un produit.
  • L'admin peut supprimer ou masquer un produit.
  • L'admin peut ajouter plusieurs photos à un produit.
  • L'admin peut gérer le stock.
  • L'admin peut gérer les catégories.
  • Le produit apparaît automatiquement dans le catalogue.
  • Une adresse web SEO est générée automatiquement.
  • Les metadata SEO sont générées automatiquement.
  • Le produit apparaît dans le sitemap.
  • Le visiteur peut rechercher un produit.
  • Le visiteur peut filtrer le catalogue.
  • Le visiteur peut consulter une fiche produit complète.
  • Le visiteur peut ajouter un produit au panier.
  • Le visiteur peut modifier les quantités.
  • Le visiteur peut retirer un produit du panier.
  • Le panier survit au rechargement de la page.
  • Le bouton WhatsApp génère automatiquement le message de commande.
  • Aucune carte bancaire n'est jamais demandée.
  • Le site fonctionne parfaitement sur mobile.
  • Le site fonctionne sur desktop.
  • Les pages produits sont accessibles aux moteurs de recherche.
  • /admin est protégé et non indexé.
